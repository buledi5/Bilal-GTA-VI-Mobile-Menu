
# Bilal GTA VI Mobile Menu

GTA San Andreas Classic Android 2.00
Architecture: ARM64
Mod loader: Android Mod Loader (AML)

## Planned Features
- GTA VI-inspired floating menu
- Player options
- Vehicle spawner
- Weapons
- Money
- Teleport
- Weather and time
- Graphics settings
- Animation selector

## Build
The project will use GitHub Actions and Android NDK.

Current stage: AML plugin loading test.
